# 第2周第3天：正交法入门

日期：2026-06-10（周三）

## 今天学的

### 1. 正交法核心概念
- **解决的问题**：组合爆炸 — 条件多了以后全排列组合数量暴增
- **因子** = 输入条件（如 keyword、page、size）
- **水平** = 每个条件的取值数（如 page 有 2 个水平：第1页/第2页）

### 2. 实际应用
选「分页列表查询」接口，3 个因子：

| 因子 | 水平1 | 水平2 |
|------|-------|-------|
| keyword | 填 | 不填 |
| page | 第1页 | 第2页 |
| size | 10条 | 50条 |

- 全排列：2×2×2 = **8条**
- 正交表 L4(2³)：**4条**，节省 50%

再加 status（启用/停用）变成 4 因子×2 水平：
- 全排列：16条 → 正交表：**8条**

### 3. 面试价值
> "有5个查询条件，你怎么设计用例？"
> → 不会正交的人说"全排列"(32条)，你说"正交表，9条就够了"
