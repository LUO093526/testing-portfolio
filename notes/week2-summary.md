## 一、本周学到的四个核心方法

### 1. 等价类划分
- **有效等价类**：规则范围内的取值，一类取一个代表即可
- **无效等价类**：规则范围外的取值，验证系统拦截能力
- 产出：注册接口 name/phone/age/grade + 列表接口 page/size 共6张分类表（54个等价类）

### 2. 边界值分析
- 三个经典位置：**刚好小于、刚好等于、刚好大于**
- 每个数值字段至少扎4个边界点 + 空值/非数字/小数/极值
- 产出：age/phone/page/size 边界值分析文档

### 3. 正交法
- 解决的问题：**组合爆炸**（非"测试重复"）
- 因子 = 输入条件，水平 = 每个条件的取值数量
- 用最少用例保证任意两因子搭配全覆盖
- 例：3因子×2水平，全排列8条 → 正交表4条，节省50%

### 4. conftest 数据管理
- fixture 的作用：**管理数据 + 管理前置逻辑**（非"写测试用例"）
- 自动登录拿 token、准备测试用户 → 注入给测试用例使用
- 产出：`tests/conftest.py`（8个 fixture，30条用例全部改用 fixture）

### 方法串联（面试话术）

```
等价类划范围 → 边界值扎关键点 → 正交法砍组合 → conftest管数据
```
