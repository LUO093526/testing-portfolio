## 今天学的

### 1. 边界值核心概念
三个经典位置：**刚好小于、刚好等于、刚好大于**

80% 的 bug 藏在边界上，面试官问"你怎么保证覆盖率"→ 用边界值回答。

### 2. 实际操作
给每个数值字段扎边界点：

| 字段 | 边界值点 |
|------|---------|
| age | -1, 0, 1, 150, 151 |
| phone | 10位, 11位(正常), 12位, 空, 非数字 |
| page | 0, 负数, 第1页, 超大页码 |
| size | 0, 负数, 1, 50(上限), 51 |

除基本边界外还补充了：空值、非数字、小数、极值。
