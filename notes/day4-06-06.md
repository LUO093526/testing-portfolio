## 今天学到了什么

### 1. pytest mark 标记系统

给测试用例打标签，用 `@pytest.mark.xxx` 装饰器：

```python
@pytest.mark.smoke      # 冒烟测试：核心功能快速验证
@pytest.mark.crud       # CRUD完整流程
@pytest.mark.exception  # 异常输入：错误参数/不存在资源
@pytest.mark.boundary   # 边界值：负数/空字符串/0值
@pytest.mark.slow       # 慢速测试：并发/大数据量
```

**关键理解**：类上的 mark 会被所有方法继承，方法上可以叠加多个 mark。

### 2. 今日标记分类

| 标记 | 数量 | 用例 |
|------|------|------|
| smoke | 4 | 健康检查(1) + 列表(3) |
| crud | 13 | 增(6) + 查(2) + 改(3) + 删(2) |
| exception | 7 | 缺字段/空body/不存在ID/特殊字符 |
| boundary | 4 | 负数年级/负数分数/空名/默认0分 |
| slow | 1 | 并发创建删除 |

重叠标记例：`test_create_missing_name` 同时是 crud + exception

### 3. pytest -m 筛选运行

| 命令 | 效果 | 用例数 |
|------|------|--------|
| `pytest -m smoke` | 只跑冒烟 | 4/20 |
| `pytest -m exception` | 只跑异常 | 7/20 |
| `pytest -m boundary` | 只跑边界 | 4/20 |
| `pytest -m "crud and exception"` | CRUD中的异常 | 6/20 |
| `pytest -m "not slow"` | CI日常：跳过慢的 | 19/20 |

**面试说法**："我用 mark 把用例分成5类，CI每次push跑 not slow，冒烟只跑4条核心，全量回归夜里跑。"

### 4. HTML 测试报告

```bash
pytest --html=reports/report.html --self-contained-html
```

- `--self-contained-html`：CSS嵌入HTML，发别人不丢样式
- 报告内容：Environment / Summary / Results / Filters
- 领导要看的：Summary（20 passed, 0 failed）
- 开发要看的：Results（哪条挂了）
