# 边界值分析文档
 
  ## 1. age（年龄）字段 — 范围 0~150
  | 边界类型 | 输入值 | 预期结果 |
  |---------|--------|---------|
  | 刚好等于（最小） | age=0 | 200，注册成功 |
  | 刚好等于（最大） | age=150 | 200，注册成功 |
  | 刚好小于（最小） | age=-1 | 400，年龄不能为负数 |
  | 刚好大于（最大） | age=151 | 400，年龄超出范围 |

  ## 2. phone（手机号）字段 — 11位数字
  | 边界类型 | 输入值 | 预期结果 |
  |---------|--------|---------|
  | 刚好等于 | phone=13800138000 (11位) | 200，注册成功 |
  | 刚好小于 | phone=1380013800 (10位) | 400，手机号格式错误 |
  | 刚好大于 | phone=138001380000 (12位) | 400，手机号格式错误 |
  | 空值 | phone="" | 400，手机号不能为空 |
   | 非数字 | phone=vsawacleajbl (11位非数字) | 400，手机号格式错误 |

  ## 3. page/size（分页）字段
  | 边界类型 | 输入值 | 预期结果 |
  |---------|--------|---------|
  | page刚好等于1 | page=1 | 200，返回第1页 |
  | page刚好小于1 | page=0 | 400，页码必须大于0 |
  | page刚好小于1 | page=-1 | 400，页码不能为负数 |
  | page超大值 | page=9999999 | 200，返回最后一页 |
  | size=0 | size=0 | 400，每页条数至少为1 |
  | size=负数 | size=-1 | 400，每页条数不能为负数 |
  | size超出上限 | size=1000 | 400，每页条数超出上限 |
